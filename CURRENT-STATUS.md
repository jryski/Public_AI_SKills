# Public skills status

Updated September 7, 2026.

This repository publishes reusable instructions and their version history. Local improvements to the diagnostic and cross-domain skills remain separate, uncommitted review work. This status update does not publish those revisions or alter their claimed versions.

The household discovery failure demonstrates a limit of instructions: a better startup payload cannot help a session that never loads it. Skills should state their participation requirements, use observable checks and distinguish unavailable coverage from absent data. Executable enforcement belongs in the application or integration, not in claims that instructions are mandatory.

Use synthetic evaluations and record exact tested versions before promotion. Do not copy private conversations, household data, credentials or deployment-specific instructions into public examples. No release or licensing change is included.
