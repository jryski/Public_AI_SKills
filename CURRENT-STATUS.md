# Public skills status

This repository publishes reusable instructions and their version history under CC BY 4.0 ([LICENSE](LICENSE)). Local improvements to the diagnostic and cross-domain skills that are not committed here are not published by this repository and do not change the versions in [skills/manifest.yaml](skills/manifest.yaml).

Instructions have limits: a better startup payload cannot help a session that never loads it. Skills should state their participation requirements, use observable checks and distinguish unavailable coverage from absent data. Executable enforcement belongs in the application or integration, not in claims that instructions are mandatory.

No claim is made that a skill improves results on any particular model, or across models. The repository checks are structural only. Before promoting a revision, use synthetic evaluations and record the exact model, version and skill version tested. Do not copy private conversations, household data, credentials or deployment-specific instructions into public examples.
